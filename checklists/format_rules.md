# Format Rules

**Important — change vs. earlier versions:**

This checklist is **not the source of truth** for concrete format values (font size, line spacing, Oxford comma, page-range notation, etc.). The source of truth is `styleguide.md`, generated by the style-resolver agent from the institution's actual citation guide.

This file contains only the **structure of check categories** — concrete values come from `styleguide.md`.

**Rationale:** Citation conventions differ between institutions, courses, and supervisors. Even within one institution, guideline versions are updated. Hardcoding leads to silent inconsistencies.

---

## Check categories (structural specification for format-verifier)

For every category below: **read concrete values from `styleguide.md`**, not from this file.

### General

- [ ] Body font (styleguide: `body.font` + `.size`)
- [ ] Footnote font (styleguide: `footnotes.font` + `.size`)
- [ ] Line spacing (styleguide: `body.line_spacing`; footnotes: `footnotes.line_spacing`)
- [ ] Page size (styleguide: `document.page_size`)
- [ ] Page margins (styleguide: `document.margins`)
- [ ] Body alignment (styleguide: `body.alignment`)
- [ ] Hyphenation as specified (styleguide: `document.hyphenation`)
- [ ] Forbidden pronouns (styleguide: `style.forbidden_pronouns`)
- [ ] Page count within range (styleguide: `document.page_count`)
- [ ] Paragraph spacing (styleguide: `body.paragraph_spacing`)
- [ ] Emphasis style (styleguide: `style.emphasis`)

### Headings

- [ ] Level 1 (styleguide: `headings.level_1.*`)
- [ ] Level 2 (styleguide: `headings.level_2.*`)
- [ ] Level 3 (styleguide: `headings.level_3.*`)
- [ ] Colour (styleguide: `headings.color`)
- [ ] Numbering convention (styleguide: `headings.numbering`)
- [ ] Max nesting depth (styleguide: `headings.max_depth`)

### Title page (elements per styleguide)

- [ ] Required elements present per styleguide (`title_page.elements`; commonly: institution name; examination type, course name, program of study; title of the work; author name, student ID; supervisor, date)
- [ ] Each element on a line of its own, unless the styleguide puts several on one line (a paragraph, or a line of a line block: `docs/reference_management.md`, "The title page")
- [ ] Quotation marks as `in_text.format_direct` shows them (an ASCII `"` becomes an English mark in the DOCX)
- [ ] Decoration/logo policy per styleguide (`title_page.decoration`; some institutions forbid any decoration or logo)

### Pagination

- [ ] Title page numbering (styleguide: `pagination.title_page`; a common convention: counted but not shown)
- [ ] Front matter (styleguide: `pagination.front_matter`; a common convention: Roman numerals; numbered unlike the main text, it is a section of its own, which `scripts/docx_pagination.py` sets after the export)
- [ ] Main text (styleguide: `pagination.main_text`; a common convention: Arabic from the introduction onward; starting at 1, it needs that section too)
- [ ] Back matter: the reference list, an appendix and what follows them (styleguide: `pagination.back_matter`; numbered unlike the main text, it is a section of its own too, from the page break before the reference list, which `scripts/docx_pagination.py` sets after the export)
- [ ] Position (styleguide: `pagination.position`)

### Table of contents

- [ ] Auto-generated
- [ ] Level emphasis (styleguide: `headings.toc_emphasis`; a common convention: level 1 bold, deeper levels without emphasis)

### List of abbreviations

- [ ] ONLY abbreviations actually used (-> `scripts/abbreviations_extract.py`)
- [ ] Alphabetically sorted
- [ ] No unused entries

### Bibliography

- [ ] Heading (styleguide: `bibliography.heading`)
- [ ] Alignment (styleguide: `bibliography.alignment`)
- [ ] Hanging indent (styleguide: `bibliography.hanging_indent`)
- [ ] Line spacing (styleguide: `bibliography.line_spacing`)
- [ ] Sort order (styleguide: `bibliography.sort_order`)
- [ ] Comma before `&` (styleguide: `bibliography.oxford_comma`)
- [ ] First edition: name or omit (styleguide: `bibliography.first_edition`)
- [ ] Series titles (styleguide: `bibliography.series_titles`)
- [ ] DOI policy (styleguide: `bibliography.doi`)
- [ ] URL policy (styleguide: `bibliography.url`)
- [ ] Access date (styleguide: `bibliography.access_date`)
- [ ] Italics for book/journal titles (styleguide: `bibliography.italics`)
- [ ] Minus-test (-> `scripts/bibliography_check.py`)
- [ ] All cited sources present
- [ ] No unused entries

### In-text citations

- [ ] Indirect format (styleguide: `in_text.format_indirect`)
- [ ] Direct format (styleguide: `in_text.format_direct`)
- [ ] Et al. rule (styleguide: `in_text.et_al.threshold`)
- [ ] Page numbers for indirect citations (styleguide: `in_text.page_for_indirect`)
- [ ] "cf." or "see" prefix (styleguide: `in_text.cf_prefix`)
- [ ] Non-breaking space before page number, also before the page range of a reference-list entry unless the styleguide says otherwise (styleguide: `in_text.nbsp_before_page`; a chapter file writes it as Pandoc's escaped space, `S.\ 12`, except a presentation's companion that is not exported with Pandoc; with citekeys, the CSL style sets it only after the label of a citekey's locator, and a page number in plain text, such as the original's page in a secondary citation's prefix, takes the escaped space)
- [ ] Page-range notation (styleguide: `in_text.page_range`)
- [ ] A source cited again right after its previous citation, on the same page or another (styleguide: `in_text.repeated_citation`): every such pair of consecutive citations in the report, one line each with its file and line, as `scripts/repeated_citations.py` lists them, also when all pass and when one line of a chapter file (a paragraph) holds several, and each checked against the value; `ebd.` or `ibid.` stands only there

### Tables and figures

- [ ] Table caption placement (styleguide: `captions.table_position`)
- [ ] Figure caption placement (styleguide: `captions.figure_position`)
- [ ] Source line placement (styleguide: `captions.source_position`)
- [ ] Decimal separator (styleguide: `numbers.decimal_separator`)

### Style

- [ ] Forbidden pronouns (styleguide: `style.forbidden_pronouns`)
- [ ] Forbidden evaluative wording (styleguide: `style.forbidden_evaluative`; e.g., "remarkable", "particularly noteworthy")
- [ ] Block quote threshold (styleguide: `style.block_quote_word_threshold`)
- [ ] Block quote layout, and where its citation stands (styleguide: `style.block_quote_format`)
- [ ] Footnote policy (styleguide: `style.footnotes`)

## Mechanical checks (automatable)

These checks run via build scripts, not manually (the commands show the flat path; long-form: the DOCX of the current format round in `08_Formal_Review/submissions/`, proposal: `04_Submission/`):

```bash
# (Windows: use `py` instead of `python3`)
# Bibliography minus-test
python3 scripts/bibliography_check.py workspace/output/document.docx

# List-of-abbreviations derivation
python3 scripts/abbreviations_extract.py workspace/output/document.docx

# Repeated citations: every pair, from the chapter files the export was made from, in its order
# (a seminar paper may give its numbered chapter folder instead)
python3 scripts/repeated_citations.py <the export's chapter files, in its order>

# Pronoun check (use forbidden pronouns from styleguide)
pandoc workspace/output/document.docx --to plain --wrap=none | \
  grep -inwE "(<forbidden_pronouns_from_styleguide>)"

# Page-range notation consistency check
# (the character class also holds a non-breaking space; "S." covers German "Seite")
pandoc workspace/output/document.docx --to plain --wrap=none | \
  grep -oE "(pp?|S)\.[[:space:] ]*[0-9]+([[:space:] ]*(to|bis|–|-)[[:space:] ]*[0-9]+)?" | sort | uniq -c
# Compare results against styleguide.md
```

## Fallback values (only if styleguide.md is incomplete)

**Relationship to the "do not guess" rule.** The format-verifier is instructed to flag missing rules with ❓ rather than guess. That rule is about **terminology and citation semantics** the agent might hallucinate from training data. The fallbacks below are a different category: pre-declared, documented conventional defaults used only for **typographic minima** when the styleguide is silent AND no guideline document exists to extract from. Using a fallback is not guessing — it is following a transparently documented default and reporting its use.

In practice: if the user has *any* guideline document, the style-resolver extracts from it and these fallbacks do not apply. The fallbacks exist for the edge case of a user with no institutional rules at all who still needs a sensible starting point. The format-verifier explicitly reports "fallback used, please verify" when any of these are applied. The list below is one illustrative, institution-neutral starting point — not a recommendation tied to any particular school:

- Body font: Arial 11pt
- Footnote font: Arial 10pt
- Line spacing: 1.5
- Page margins: 2.00 cm on all sides
- Body alignment: justified, with hyphenation
- Headings: 16pt / 14pt / 11pt, all bold, left-aligned
- Numbering: without trailing period (1 Introduction, not 1. Introduction)
- Page numbers: title page (counted, invisible), front matter Roman, main text Arabic
- Bibliography: left-aligned, hanging indent 1.27 cm
- Access dates and page numbers for indirect citations: these are citation *semantics*, not typographic minima — leave them to `styleguide.md` and do not apply a default.

**Important:** Fallback values are NOT a substitute for an extracted `styleguide.md`. They apply only where parts remain unclear and no institutional rule exists to extract.
